## 核心结论

365 天里，BTC 平均每天有 2.68 段「6 小时内走完、涨幅 ≥1%」的上涨波段，中位涨幅 1.67%、中位用时 75 分钟。所以「各种波段都错过」是真的。

但 4 类最常见的短线买点（急跌收复、收敛突破、趋势回踩、布林下轨回归）按真实成本跑完一年后，即使按更便宜的 BNB 抵扣成本（来回 0.19%）计算，样本外每笔期望值也全部为负。按你实际的 0.24% 算，还要再差约 0.05%。

更要警惕的是：把止盈收窄到 0.5 倍止损，急跌收复的胜率能到 61%，每笔却仍亏 0.17%。新系统不能只求「多发信号」或「高胜率」，要同时管住四件事：成本、进场位置、过滤、出场。

## 二、本项目实测：为什么现有规则不赚钱

测试方法：每根 15 分钟 K 线收盘时判断信号，下一根 5 分钟 K 线开盘价进场；止损和止盈同时被触及时一律算止损；最长持有 6 小时。下表成本按 BNB 抵扣的 0.19% 计，是偏乐观的口径。你不抵扣，实际成本为 0.24%，每笔期望值要再减约 0.05%。同一形态持仓期间不重复开仓。

来源：币安 BTCUSDT 5m / 15m / 1h，2025-10-17 至 2026-10-17，365 天全样本。胜率定义为扣费后净收益大于 0 的交易占比。

## 四、双引擎分工

原则：所有价格、止损、仓位和数量由云端量化引擎计算，并且可以回放复现。DeepSeek 不写任何价格，只能否决、降级、复盘和解说。AI 每一次否决都会被跟踪：被否决的信号照样进入影子仓结算，满 100 笔后，如果否决没有提高期望值，AI 否决权自动关闭。

### 引擎 A：云端量化引擎

确定性，每根 K 线收盘计算一次。

| 任务 | 说明 |
| --- | --- |
| 数据 | 现货 1m/5m/15m/1h/4h/1d、bookTicker 实时盘口；合约 OI、资金费率、主动买卖比（5m） |
| 环境评分 | 1D / 4H / 1H 三层趋势，加关键价位、波动分位、交易时段 |
| 候选生成 | 5 个形态模块（见第五节），偏重召回率，每天 3–6 个候选 |
| 交易计划 | 进场挂单区间、结构止损、TP1 / TP2、时间止损、按风险算仓位 |
| 统计过滤 | 元标签模型输出胜率 P，并计算扣费后期望值 |
| 止损监控 | WebSocket 秒级盯盘，覆盖每一笔实盘和模拟仓 |
| 学习与晋级 | 三重障碍标注、滚动前推验证、DSR / PBO 门槛、版本发布与回滚 |

### 引擎 B：DeepSeek AI 预警

只读结构化数据，不写价格。

| 任务 | 说明 |
| --- | --- |
| 第二意见 | 对交易级候选输出「通过 / 降级为观察 / 否决」，理由从固定标签里选，附置信度 |
| 异常识别 | 急跌是否伴随强平潮、资金费率极端、OI 骤降，或在关键位假破 |
| 中文解说 | 买入卡片和止损提醒的一句话原因；数字一律引用引擎 A |
| 每日复盘 | 逐笔复盘实盘与影子仓：亏损归因、你的出场与系统出场的差距 |
| 假设提案 | 每周提出不超过 3 条可检验假设（JSON），交给引擎 A 回测，通过门槛才晋级 |
| 失效降级 | AI 超时 8 秒或返回格式错误时视为「通过」，不阻塞推送，并单独记录 |

### 信号流水线

| 步骤 | 负责引擎 | 延迟预算 | 失败时 |
| --- | --- | --- | --- |
| 1. 15m / 5m K 线收盘，计算环境与候选 | A | 收盘后 ≤ 3 秒 | 数据过期就跳过本根 |
| 2. 成本与目标空间门槛 | A | < 100 毫秒 | 不发 |

## 七、止损与离场提醒

每笔实盘买入和每笔影子仓都由引擎 A 秒级监控。止损提醒走现有的设备专属推送通道（exit_delivery），优先级高于买入推送。

| 级别 | 触发条件 | 推送内容 | 动作建议 |
| --- | --- | --- | --- |
| 计划 | 开仓时 | 进场价、止损价、TP1、TP2、时间止损时刻、建议数量 | 立即在币安挂止损单 |
| 接近 | 价格距止损 ≤ 0.15%，或 15m 收盘跌回收复价下方 | 结构正在失效 | 考虑减仓 |
| 止损 | 成交价 ≤ 止损价 | 止损离场 | 立即卖出 |
| 时间 | 90 分钟未到 +0.3R，或持有满 6 小时 | 动能不足 | 市价或挂单离场 |
| 止盈 | 触及 TP1 | 卖出 50%，止损上移到保本 | 跟踪剩余仓位 |
| 环境 | 5 分钟内跌 ≥ 1%，或 1H 收盘跌破环境支撑 | 急跌风险 | 所有多单离场或减半 |

## 八、实盘与模拟仓同步、数据闭环

### 录入一笔真实买入时

1. 系统按同一时间、同一价格自动开一笔 500 USDT 的模拟仓，并关联最近的信号；没有对应信号的标记为「主观单」。
2. 记录开仓那一刻的完整特征快照，包括环境、形态、衍生品、盘口价差和延迟。
3. 生成「系统出场孪生仓」：按系统规则自动止损止盈，用来和实际出场对比。
4. 录入卖出后，模拟仓同步平仓，结果自动生成三重障碍标签。

### 系统自己的每个候选

所有候选，包括被 AI 否决的、只到观察级的，都开影子仓并按规则结算。这样训练数据不会只包含被推送的信号，可以避免选择偏差。

实盘成交主要用来校准滑点和延迟，并评估执行纪律；同时作为加权样本加入训练。不单独用于训练，因为数量太少且有选择偏差。

## 九、分阶段自主进化

上线第一天就用 2 年历史 K 线回填候选和标签，每年约 1,000 个以上样本，不必从零等待。进化只允许在下面的边界内调参；硬约束永远不能被学习改动。

| 阶段 | 进入条件 | 能改什么 | 方法 |
| --- | --- | --- | --- |
| L0 规则 | 现在 | 无，参数取自先验与本次回测 | 确定性规则加成本门槛 |
| L1 统计校准 | ≥ 200 个已标注候选（含历史回填） | 各形态的 P 阈值、进场偏移、止损缓冲（均有上下限） | 逻辑回归元标签模型，清洗前推交叉验证加禁区 |
| L2 自适应 | ≥ 500 个样本，且 L1 稳定 30 天 | 分环境阈值、TP 倍数、时间止损；滚动 90 天重训 | 梯度提升树、CPCV、PBO |
| L3 AI 假设循环 | L2 稳定 | 新增过滤特征或新形态（须通过回测） | DeepSeek 提案，引擎 A 检验，再按晋级流程上线 |

### 晋级门槛（全部满足）

| 指标 | 门槛 |
| --- | --- |
| 样本外交易数 | ≥ 60 |
| 扣费后期望值 | ≥ +0.10%/笔，自助法 95% 下限 > 0 |
| 胜率（净收益 > 0） | ≥ 52%，目标 55%–62% |
| 盈利因子 | ≥ 1.30 |
| 过拟合 | PBO < 0.30；试参 > 20 组时 DSR > 0.95 |
| 频率护栏 | 交易级 0.5–6 条/天 |

### 上线流程与回滚

| 阶段 | 规则 |
| --- | --- |
| 研究 | 离线回测，生成验证报告 |
| 影子 14 天 | 只记录、不推送 |
| 试运行 14 天 | 推送，卡片标注「试运行」 |
| 正式 | 进入交易级 |
| 自动回滚 | 最近 30 笔期望值 < 0，或回撤 > 6R |
| 不可学习 | 只做 BTC、只做多、AI 不写价格、成本下限、止损 ≤ 1.2%、持有 ≤ 6 小时、熔断 |

## 十、关于「高胜率」的验收口径

以下两项必须同时满足，才算达到上线门槛。

| 指标 | 门槛 |
| --- | --- |
| 胜率（扣费后净收益 > 0） | ≥ 55% |
| 每笔期望值 | ≥ +0.10% |
| 止损提醒延迟 | ≤ 5 秒 |
| ≥1.5% 波段在前 1/3 段内有候选 | ≥ 50% |

以上指标是上线门槛，不是收益保证。研究显示 BTC 短线可预测性会随时间变化，单条规则在样本外经常失效。系统做得到的是：每个信号都有数据支撑的止损和期望值；形态失效时自动降级；不会把胜率高但期望值为负的设置推送出去。
