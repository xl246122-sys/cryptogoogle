## 实现与使用边界

| 项目 | 交付内容与边界 |
| --- | --- |
| C01 六周期研究数据 | 新增 SpotResearchFeed，每 30 秒持续写入 BTCUSDT 的 1m/5m/15m/1h/4h/1d 闭合 K 线。主键为市场、周期、开盘时间；验证时间对齐、OHLC、成交量和收盘状态。重启续接尾部并逐批修复内部缺口，重复抓取幂等。空库先取每周期 300 根，单周期单请求上限 1000；这不是两年历史已齐全。页面展示实际数量、区间缺口和尾部待补。 |
| C02 输入契约 | `inputs-v2.1` 显式保存既有短窗 47/47/95/47/47、300 根上下文容量、SMA 种子 EMA、总体标准差 BOLL、Wilder RSI/ATR、规则/成本/结算版本。上下文 REST 的 300 根包含当前形成根，过滤后高周期通常 299 根；15m 上下文截取最多 300 根，S5 保持既有 30 天读取。未改变这些原有数值。实盘存档冻结时间、上下文、衍生品、成本与输入契约，回放共用 evaluate，契约不匹配拒绝评估。 |
| C03 候选漏斗 | 记录无形态、环境关闭、发现、筛选、可执行、抑制、AI 意见、推送处理、平台回执、手机事件、实际操作和结算阶段。候选 ID 贯穿，阶段事件幂等；不是成交计数。引擎继续检查全部候选用于诊断，第一优先级可执行信号不变，补充显式到期判断。 |
| C04 AI 接线 | v2 复核复用服务端既有加密凭据、provider/model 和开关，支持 DeepSeek/Gemini 适配。只读引擎 A 摘要，8 秒时限；关闭、无 key、超时、格式/调用错误均 PASS 并记录原因。拒绝数字、百分比和换行的意见内容；不会接受 AI 修改价格。状态接口不返回密钥。 |
| C05 AI 效果核对 | 意见、候选、影子结果关联，提供分环境 VETO/PASS 的有效样本数、平均 R 及排除数量。保留原有 100 个否决结算后的否决权限审查。当前有效研究样本为 0，状态 UNVERIFIED；一次 API 调用成功不代表改善胜率。 |
| C06 成交核对 | 补录保留实际数量、时间和 USDT/BTC/BNB 费用。新增标准 JSON 数组/本应用导出记录导入，先预览后确认；按成交编号/交易所成交编号识别重复，冲突要求逐笔更正。导出的已替代/拒绝记录不重复导入，分批成交排序后核验库存。不是任意交易所 CSV 导入器，也没有接入个人交易所密钥或自动下单。 |
| C06 研究同步 | 用户事件先持久写入日志，再幂等镜像至研究库；失败有 ERROR 标记，后台重试。追加更正保留原成交，活跃成本样本/均价排除被替代成交。更正影响的 SYSTEM 样本不进入正式晋级数据，历史标签不覆写；需要另行有证据的重放。实际库存及收益以当前用户日志投影为准。 |
| C07 账户风险 | 用户手工填写权益并声明全部 BTC 多单已补齐；记录来源和服务端更新时间。仅在 15 分钟内且已知持仓都有退出计划时展示合计计划风险和 0.5% 单笔预算；缺失、陈旧、覆盖不全时显示未知。15 分钟是界面信息有效期，不是新增交易阈值。未连接交易所核验，风险金额也不承诺覆盖跳空等额外损失。 |
| C08 身份隔离 | 每条本地队列记录绑定保存连接时生成的身份范围；发送捕获原目标，切换连接后停止后续发送，迟到回执只确认原记录。旧/离线未绑定队列隔离，需用户明确绑定当前连接后发送，不自动迁移；不会复制密钥进成交记录。重新保存连接会生成新身份范围，旧范围数据保留并可导出。 |

同时修复 B 阶段遗留的快捷模拟服务端平仓成本：QUICK_PAPER_V2 按入场冻结成本和剩余初始本金分摊，原 QUICK_PAPER_V1 仍保留旧口径。真实成交现金流不重复扣模拟成本。

手机入口：系统守护中的“研究数据与执行链路”和“账户风险（手工记录范围）”；实际成交补录区域提供标准 JSON 预览导入、旧记录归属确认及原有逐笔更正。标准成交字段沿用 ExecutionFill：fillId、positionId、side、price、quantity、executedAtMs、commission、commissionAsset、commissionAssetUsdtRate、referencePrice、referenceAtMs、timeApproximate，exchangeTradeId 可选。未知手续费填 null，不用零代替未知。
