## 实际改动

| 项目 | 实现与边界 |
| --- | --- |
| 成本快照 | `cost-v2.1` 保存工作成本、来源、可见时间、适用时间以及费用/滑点/价差处理方式。工作成本不低于适用下限；当前默认无 BNB 抵扣，0.24%。只有明确且经核验的折扣证据才允许 0.19%，本次未开启抵扣。 |
| 生产贯通 | 研究账本提供评估时可见的成交校准；快照写入评估输入及信号，筛选、入场复核、仓位、保本、模拟结算和手机解析读取相同成本。真实成交导入时保存 availableAtMs；缺少可见时间的旧校准样本不用于历史决策。历史回放读取存档快照，不查询未来校准。 |
| 模拟口径 | 参考价格模型，完整往返成本按初始名义本金扣一次，分批退出按初始仓位权重分摊。TP1 卖一半不等于整笔取得 TP1 收益。这个模型不是实际成交或盘口撮合模拟。 |
| 实际成交 | 前后端均按实际数量、成交价及费用现金流汇总。BTC 费用改变库存，BNB 费用按成交时汇率折算；不再重复扣预设滑点。部分卖出仅显示已实现收益，全部平仓且费用齐全才显示整笔净收益。 |
| 入场分钟 | 保存精确 filledAt。仅有跨入场时刻的分钟 OHLC 时标记 PATH_UNCERTAIN，不跳过整根 K 线。接口支持具有完整覆盖证明的成交后 tick 路径，回归验证入场前低点不触发退出；当前生产闭合 K 线结算没有这种完整 tick 证据时仍标不确定。 |
| 退出时间 | 新结算版本 `settlement-v2.1` 修复第 360 分钟 TP1 分支绕过余仓退出的问题。同根止损优先；截止后目标不记作截止前命中。跨越精确 90/360 分钟但缺少边界报价时，只记录带不确定标记的保守退出情景，不宣称恢复了真实成交。 |
| 真实持仓 | 提醒、查阅确认与实际卖出仍分开。到期未录入卖出保留库存，新增“超时未平仓”显示。保本提醒按实际平均买价与原计划成本计算。 |
| 标签与旧记录 | 新标签保存成本/执行版本和路径质量。PATH_UNCERTAIN 的标签编码为 0，不作为已证实赢/亏；晋级样本读取排除旧结算版本和不确定路径。质量接口同时给出旧记录数量、不确定比例及包含不确定交易的止损情景敏感性，不能把排除后的胜率单独解释为提升。 |
| 修正重放 | 新增 `label_replays`，通过原标签编号和输入哈希关联，重复重放幂等。原标签不覆写。重放仍需要足够的原计划和路径数据；缺失证据不能凭空补齐。 |
| 旧一键模拟 | 新记录使用 QUICK_PAPER_V2，买入时冻结云端成本快照，卖出分摊原买入成本。旧 QUICK_PAPER_V1 持仓及收益单列，保留原 0.11% 口径，不合并为新模拟统计。 |

不确定交易仍保留按保守 K 线规则得出的情景收益与腿记录，`eligibleForValidation=false`，另保存 `conservativePnlPct` 的全仓止损压力情景。它不是实际收益、可信的分钟内路径或包含跳空滑点的绝对亏损下界。短于观察窗的 SAMPLE_END、粗于 1m 的路径及缺口也不进入正式验证。旧的 5m 基线只能继续作诊断；D 阶段仍需以完整数据重做独立验证和不确定性分析。
